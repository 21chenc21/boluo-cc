# v1-dev 夯实批规划 (2026-07-10 定稿, sp46 链式战役收官产物)

目标: 决策对细小扰动鲁棒 — "无关死牌不该改变摆法" (边界摆动测试为验收标准).

## 背景 (sp46 链式战役的终局发现)

- 链式单案微调把所有 F11 角落推到决策边界 ±0.1, 每发弹翻一个尘埃掀两个尘埃
- 边界摆动实验: 64 案塞一张无关 2s 死牌, 摆法从 −9.5 错线翻成正线 — 实战中这些角落本就是掷硬币
- 真钱账: 万分位几何 × 几分 = 几厘/手, 已在 duel 噪声 (±0.2/局) 地下室

## 三层夯法

### ① 数据层: F11 家族批 + 扰动增强 (治本)
- F11 家族: R1/R2 含对子 + 对子出路死牌 0-2 张随机 + 底道强弱随机 → 系统重校准"死牌×对子行位"轴
  (病理: usedCards 特征响应倒挂 — 删死牌 d5 自摆对, 见 129/130 验尸)
- **gen 扰动增强** (新 flag): 每个种子态同时出塞 1-2 张无关死牌的变体, 标签不变 —
  把不变性直接写进数据
- 种子粮已备: fam-60/64/129/130-exact (v0-dev-sp27/)

### ② 服务层: 平局带确定性决胜 (一天工作量, 可先行)
- top-K 差距 < ε(0.5) 时不信 argmax, 按固定教义序决胜: f89 低者 → 范路宽者 → 规范序
- 不改变"对错" (平局无对错), 消灭随机性: bench 不闪、prod 可复现、硬币固定落安全面
- 与已退役的薄边搜索不同: 确定性决胜无 rollout 噪声问题

### ③ 特征层: 因果化 outs 特征 (sp47 式特征批)
- 现状 f52-68 = 原始 rank_remaining, 网络自己组合"对子还剩几张出路" → 映射脆
- 直接给算出的 pairOutsRemaining / drawOutsRemaining → 近线性映射, 天然抗扰动
- 换血税照付 (语义迁移: 大改特征=数据换血 + DATA_VERSION bump + 单元测试)
